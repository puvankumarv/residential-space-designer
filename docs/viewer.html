See the room in 3D.

Every layout the skill designs can be turned into a 3D model, with furniture shaped by type: beds, sofas, cabinets with doors, worktops, appliances. These are the shipped examples, each one checked against the safety and design rules first. Drag to orbit, scroll or pinch to zoom. The ceiling is left off so you can look in.

Twins' room, 3.4 × 3.4 m: offset L-loft with a desk and wardrobe underneath.Furniture is shaped by type at its real size. Download .glb ↓

1. Export a layout

Python 3, nothing to install. Writes a .glb you can open in Blender, Windows 3D Viewer, macOS Quick Look, or this page.

python3 residential-space-designer/scripts/layout_to_gltf.py \
  layout.json room.glb

2. Render a walkthrough

With Blender, or pip install bpy on Python 3.11. Orbit from above, or stand in the doorway and look around.

blender -b -P residential-space-designer/scripts/blender_walkthrough.py \
  -- room.glb walk.mp4 --mode walk
