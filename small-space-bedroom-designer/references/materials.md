# Materials vocabulary

Use these names in the BOM and in the layout's `material` fields. The render stage maps them to textures.

| Material id | Use | Notes |
|---|---|---|
| `steel_square_tube_galv` | Raised-bed and multi-bed frames | Welded and fixed with expansion bolts; an engineer confirms the anchoring [80, 82] |
| `wood_panel_eco` | Cladding, cabinets | Low-formaldehyde (E0/E1 or equivalent) board |
| `solid_wood` | Steps, guardrails, desk tops | Rounded edges for kids |
| `wood_veneer` | Wardrobe fronts | |
| `gypsum_board` | Partitions, stepped ceilings, false walls | Moisture-resistant grade in damp rooms |
| `fire_board` | Partitions near beds | |
| `slatted_base` | Bed foundations | For ventilation |
| `padded_panel` | Wall beside beds, headboards | Upholstered |
| `glass_frosted` / `glass_fluted` / `glass_tempered` | Dividers, sliding windows on upper beds | Always tempered or laminated |
| `aluminium_panel` | Wet areas | |
| `stone_marble` | Vanity and counter tops | |
| `tile_large` | Bathroom and balcony floors and walls | |
| `fabric_curtain` | Privacy curtains, ceiling track | Blackout option |
| `antislip_tread` | Steps and ladder rungs | |
